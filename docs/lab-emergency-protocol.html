🚨 Emergency Protocol 🚨

Activate backup power

If the power is still off, activate the emergency backup power system.

  1. Locate the gray metal electrical panel on the wall.
  2. Unlock the combination lock.
  3. Remove the lock from the lever.
  4. Push the lever upward until it clicks.

Once power is restored, you'll be able to get into the lab.

Access the lab

To keep the lab SeCuRe, we change the access code periodically.

  1. Locate the black electronic keypad on the lab door.
  2. Enter the 6-digit code.
  3. If the code is correct, the door will unlock.
  4. Push the door open.

Once you're in the lab, call Darryl; he'll know what to do from there.
